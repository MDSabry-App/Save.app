# Build a Production-Ready Developer & Personal Utility Dashboard

Build a modern, practical, desktop-ready web application called:

**SaveDesk — Developer & Personal Utility Dashboard**

The application should be a real daily-use productivity tool for developers, creators, freelancers, students, and regular users.

The goal is NOT to create an AI-looking dashboard.

The goal is to create a **human-designed, practical, fast, organized personal utility workspace** that can later be packaged as a Windows/macOS/Linux desktop application using **Electron or Tauri**.

---

# 1. Core Requirements

Build the application as a responsive SPA.

Preferred stack:

- React
- TypeScript
- Vite
- Modern CSS
- LocalStorage or IndexedDB for persistence
- Modular component architecture
- No unnecessary backend
- No authentication
- No cloud dependency for core features
- No Docker
- No external database required

The application must work locally and remain useful without an internet connection wherever possible.

Structure the code so that future desktop integration with Electron or Tauri is straightforward.

Do NOT build everything as one giant component.

Use reusable components, services, hooks, utilities, types, and storage abstractions.

```
shell
```

Use secure IPC boundaries.
